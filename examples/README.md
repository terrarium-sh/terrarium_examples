# Explored Examples

Setups we tried, explored or just checked, but never really used. They worked
when we wrote them, but nobody runs them day to day, so they may lag behind
the projects they run.

## Examples

- [dsh-superagent](dsh_superagent) — Run DeepSeek's dsh-superagent research prototype, a proactive GitHub coding agent, on OpenCode Go's DeepSeek V4.1 Flash, with egress only to its model, GitHub and its package registries.
- [OpenCode v2 Dev](opencode_v2_dev) — Run the OpenCode 2 server over a folder of projects, with config in a host folder and sessions on a persistent volume.
