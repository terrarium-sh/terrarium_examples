# Official Examples

Setups we use, or have used at some point in time.

## Examples

- [Codex Dev](codex_dev) — Run Codex CLI in an isolated development microVM.
- [Containers](containers) — Run Docker/OCI images with Podman, with egress only to Docker Hub.
- [GoFast Dev](gofast_dev) — Build GoFast apps with the `gof` CLI preinstalled in an isolated development microVM.
- [pi-durable](pi_durable) — Run a crash-proof assistant on any OpenAI-compatible API (OpenCode Go by default), built on pi.dev's durable agent harness, with egress only to its model and package registries.
